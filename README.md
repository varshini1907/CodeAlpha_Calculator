# Calcify Pro ✦

A modern, responsive scientific calculator built using
HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations
- Scientific calculations
- Real-time result preview
- Calculation history
- Local Storage integration
- Dark and light themes
- Keyboard support
- Copy results
- Responsive design
- Error handling

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Start calculating!

## Keyboard Shortcuts

- 0–9: Numbers
- + - * /: Arithmetic
- Enter: Calculate
- Backspace: Delete
- Escape: Clear
- %: Percentage

## Scientific Mode

Includes trigonometric functions (degrees), square root,
square, logarithms, factorial, constants, and reciprocal.
